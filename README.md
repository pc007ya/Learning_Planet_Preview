# Learning Planet isolated acceptance preview

This is an explicitly approved public test copy of the existing public application. It contains no exported student accounts or progress. The original website and formal domain are unchanged.

The preview reads the pinned public source and references the separate Learning_Planet_Assets site. Normal login, if used, still uses the existing Firebase backend; this is not a new account database or a load-test target.

Deployments are manual only. No Firebase deployment credentials or commands are used.
